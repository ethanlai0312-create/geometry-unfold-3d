# 展境 · 立體幾何實驗室

全繁體中文的 Three.js 立體幾何展開網站。採用 Vite 與原生 JavaScript，可部署於 GitHub Pages，無後端及付費 API。

## 執行

安裝 Node.js 24 與 pnpm 11 後，在此資料夾執行：

```sh
pnpm install
pnpm dev
```

開啟終端顯示的本機網址。正式建置與檢查：

```sh
pnpm test
pnpm build
pnpm preview
```

`dist/` 是可部署的靜態網站。請使用 HTTP 伺服器開啟；不要直接以 file:// 開啟 HTML。

## 使用方式

1. 首頁選擇正方體、長方體、圓柱體、圓錐體或球體。
2. 選擇數字方案，預設為方案 1 與完整立體狀態。
3. 按展開、折疊、暫停／繼續或重播；進度滑桿可任意定位。
4. 拖曳旋轉，滾輪或雙指縮放。「重設視角」恢復自動取景。
5. 調整尺寸，查看公式與關鍵數值，或匯出平面輪廓 SVG。

## 數學模型

- 正方體：枚舉六連方格，以平面旋轉與鏡射消除重複，再以折疊面法向量篩出 11 種方案。
- 長方體：取五種不同連接布局，依各面的空間軸向指定實際長寬。剛性面繞公共棱旋轉。
- 圓柱：以曲率 k=(1-t)/r 展平側面，位置為 (sin(ks)/k, v, (1-cos(ks))/k)，k=0 時採極限 (s,v,0)。側面保留弧長。底面完整切離並移動至三種不同布局。
- 圓錐：母線 ℓ=√(r²+h²)，內在角度範圍 2πr/ℓ，以 q 從 r/ℓ 增至 1 的圓錐族保持曲面度量。底面完整切離，放置於三種不同位置。
- 球體：經線分瓣、赤道半瓣、緯度分帶三種近似。球面具有正高斯曲率，無法無失真攤平；分片展平涉及剪切或伸縮，不能視為精確紙模。

## 結構

- `src/math/`：展開圖枚舉及曲面公式。
- `src/models.js`：Three.js 模型、鉸鏈及網格更新。
- `src/scene.js`：光照、攝影機、互動與資源清理。
- `src/main.js`：介面與動畫狀態。
- `src/content.js`：繁體中文文案、公式與數值。
- `src/export.js`：平面輪廓 SVG 匯出。
- `tests/math.test.js`：幾何與數值檢查。

## GitHub Pages

建立公開倉庫 `geometry-unfold-3d`，將完整專案（不含 node_modules、dist）推送至 `main`。在倉庫 Settings → Pages → Build and deployment 選擇 GitHub Actions。

已附 `.github/workflows/deploy.yml`：推送 main 後自動安裝鎖定依賴、執行數學測試、建置與部署。Vite 使用 `base: './'`，支援專案子路徑。憑證不應加入原始碼。

## 驗證範圍與限制

已通過六組數學測試，以及 Chromium 瀏覽器中 25 個方案的選擇和 0%／100% 定位。已實測播放、暫停、反向折疊、尺寸調整；已檢視 1366px 桌面及 390px 手機布局。

尚需補驗：真實手機手勢、Safari／Firefox、SVG 下載成品，以及所有尺寸與中間進度的碰撞情況。SVG 為輪廓匯出，不含黏貼邊與尺寸文字。球體不可作無失真紙模。

GitHub 發佈結果必須以實際 Actions 成功與公開網址檢查為準；本文件不表示網站已發佈。
