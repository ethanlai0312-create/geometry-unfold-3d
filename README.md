# 展境 · 立體幾何實驗室

全繁體中文的 Three.js 立體幾何展開網站。採用 Vite 與原生 JavaScript，可部署於 GitHub Pages，無後端及付費 API。

## 執行

安裝 Node.js 24 與 pnpm 11 後，在此資料夾執行：

```sh
pnpm install
pnpm dev
```

開啟終端顯示的本機網址。正式建置與檢查：

```sh
pnpm test
pnpm build
pnpm preview
```

`dist/` 是可部署的靜態網站。請使用 HTTP 伺服器開啟；不要直接以 file:// 開啟 HTML。

## 使用方式

1. 首頁選擇正方體、長方體、圓柱體、圓錐體或球體。
2. 選擇數字方案，預設為方案 1 與完整立體狀態。
3. 按展開、折疊、暫停／繼續或重播；進度滑桿可任意定位。
4. 拖曳旋轉，滾輪或雙指縮放。「重設視角」恢復自動取景。
5. 調整尺寸，查看公式與關鍵數值，或匯出平面輪廓 SVG。

## 數學模型

- 正方體：枚舉六連方格，以平面旋轉與鏡射消除重複，再以折疊面法向量篩出 11 種方案。
- 長方體：取五種不同連接布局，依各面的空間軸向指定實際長寬。剛性面繞公共棱旋轉。
- 圓柱：以曲率 k=(1-t)/r 展平側面，位置為 (sin(ks)/k, v, (1-cos(ks))/k)，k=0 時採極限 (s,v,0)。側面保留弧長。底面先沿保留的邊界接點向外翻開，側面再展平，三種方案的接點位置不同。
- 圓錐：母線 ℓ=√(r²+h²)，內在角度範圍 2πr/ℓ，以 q 從 r/ℓ 增至 1 的圓錐族保持曲面度量。底面繞保留接點向外翻轉 180°，再隨側面展平；三種方案使用圓弧上不同的接點。
- 球體：共極點的經線分瓣、以赤道接點連接的兩組半球瓣、保留共邊的緯度分帶三種近似。每片保留至少一個接點；分片數可在 8–1024 間以 2 片遞增調節。球面具有正高斯曲率，無法無失真攤平；分片展平涉及剪切或伸縮，不能視為精確紙模。

## 結構

- `src/math/`：展開圖枚舉及曲面公式。
- `src/models.js`：Three.js 模型、鉸鏈及網格更新。
- `src/sphere-shader.js`：與 CPU 公式對應的顯示卡變形，將球體合併為表面及切線兩次繪製。
- `src/scene.js`：光照、攝影機、互動與資源清理。
- `src/main.js`：介面與動畫狀態。
- `src/content.js`：繁體中文文案、公式與數值。
- `src/export.js`：平面輪廓 SVG 匯出。
- `tests/math.test.js`：幾何與數值檢查。

## GitHub Pages

建立公開倉庫 `geometry-unfold-3d`，將完整專案（不含 node_modules、dist）推送至 `main`。在倉庫 Settings → Pages → Build and deployment 選擇 GitHub Actions。

已附 `.github/workflows/deploy.yml`：推送 main 後自動安裝鎖定依賴、執行數學測試、建置與部署。Vite 使用 `base: './'`，支援專案子路徑。憑證不應加入原始碼。

## 2026-10-17 修正與驗證

- 所有模型在進度 0% 隱藏切線，前 12% 僅讓細線漸入，其後開始移動。反向播放使用同一個確定性映射。
- 統一材質與面朝向，球體閉合時使用連續的徑向法線，修復赤道光影斷層。
- 圓柱、圓錐底面保持剛性與接點，不再平移遠離側面。
- 球體使用非線性的向外舒展路徑；1024 片仍為真實分片。高片數僅抽樣顯示切線、淡化透明度及極點切線，不減少幾何片數。極密分片在縮小視圖中會受像素解析度限制，可放大觀察。
- 15 組數學／回歸測試通過，包含接點、面朝向、逆向定位、尺寸、剛性底面、抽樣碰撞與 SVG 索引。
- 開發伺服器的 `/tests/browser.html` 可重跑 WebGL2 公式比對與 1024 片壓力測試。實機 3,456 點 CPU／GPU 比對通過（半徑 1，容許誤差 0.0002）；本機最大誤差約 0.0000882。
- Chromium 中已檢查全部 25 種方案的切換、起點與終點；390px 手機寬度下沒有水平溢出，控制按鈕均在畫面內。

碰撞檢查涵蓋取樣的進度及極端尺寸，並搭配曲面／底面的幾何分離條件；不是對所有浮點參數的形式化證明。球體代表可伸縮薄膜，無法當作不可伸縮紙張的精確展開。接點是理想零厚度鉸接，沒有模擬紙張厚度或材料受力。

真實手機手勢、Safari 與 Firefox 尚未在實體裝置測試；本機效能不能保證所有裝置同速。SVG 匯出為輪廓，不含黏貼邊與尺寸文字。
